# Pinocchio Tutorials: Quick Start

## What should be in the folder

After unzipping, the folder should contain:

- `01_import_and_visualize.ipynb`
- `02_forward_kinematics.ipynb`
- `03_transformations.ipynb`
- `04_dynamics.ipynb`
- `05_coal_distances_and_collisions.ipynb`

## Recommended setup

1. Download the zip file and extract it.
2. Open the selected notebook in Google Colab.
3. Follow the tutorials through and complete the exercises.
